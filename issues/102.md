## Task

Our goal is that within each book folder (like in ./ebook-font-l10n/adrian-frutiger--typefaces-the-complete-works/ ) a TMX (Translation Memory eXchange) file is created. We want to segment the text into sentences, and then get the translations of each sentence. 

We want to do it in software. That means, that we should first produce markdowns, then we could use something like https://pypi.org/project/semantic-text-splitter/ and then embedd the stentences. Then we should use some kind of clever way to determine parallel sentences. In this process if some portion of the text is not easy parallelizable across all languages, we can omit it. That means if I have the texts: 

"Adam is a man. He’s 30. He works hard." 
and 
"Adam to trzydziestolatek. Ciężko pracuje."

We’d only store in the TMX "He works hard." and "Ciężko pracuje." as parallel sentences. 

The tool should work as fast as it can. It should emit compact TMX files, not overly verbose. 

You should first figure out which PDF-to-markdown tool is the best, taking ALL the books into acocunt in ./ebook-font-l10n/

Then settle on the best PDF-to-markdown tool, and incorporate it into the tool. 

Then use some portion of ./ebook-font-l10n/adrian-frutiger--typefaces-the-complete-works/ to develop our tool. Weigh both embedding models, decide which one is the best on our task. Make the whole process efficient.
